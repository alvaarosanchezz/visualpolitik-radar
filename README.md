## Estructura

| Archivo | Qué es |
|---|---|
| `radar_dashboard_YYYY-MM-DD.html` | Shell del dashboard de cada día |
| `data_YYYY-MM-DD.js` | Contenido editorial (`VP_DATA`) de cada día |
| `dashboard.js` | Lógica de render compartida |
| `styles.css` | Estilos compartidos |
| `index.html` | Redirige al informe más reciente |

Las imágenes se sirven desde Wikimedia Commons (remotas), no se almacenan aquí.

**Nota:** Este repositorio NO contiene tokens, claves ni material editorial privado (ver `.gitignore`).
